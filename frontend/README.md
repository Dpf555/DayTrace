# Vue 前端

当前仅有目录骨架，尚未初始化 Vue 项目、安装依赖或实现页面。

## 目录职责

- `src/views/`：登录、记录、日历、回收站和账号设置页面。
- `src/components/`：可复用的界面组件。
- `src/api/`：调用 Spring Boot 业务 API。
- `src/router/`：页面路由。
- `src/assets/`：由构建工具处理的静态资源。
- `public/`：原样发布的公开静态资源，不放私人文件或密钥。

建议使用 Vue 3、Vite、Vue Router 和 JavaScript。工程依赖确认后补充启动命令。

浏览器仅访问 Java 业务 API；AI 建议必须经过用户预览和确认。Markdown 与模型文本使用一致的安全渲染规则。
