# 需求边界访谈记录

状态：用户已整体确认需求边界及初步阶段安排，并授权进行架构设计。主要业务代码仍由用户编写。

## 已确认范围（2026-09-24）

- 项目用于毕业设计，预计 2027 年 4 月完成；学校或导师的具体要求尚不明确。
- 学生编写主要代码；AI 助手负责辅导、需求澄清、架构讨论、知识讲解和代码审查，框架共同决定。
- 已有技术基础：Java、Spring Boot、Vue、基础 Python；使用 Python LangChain 实现 AI 部分，架构方向见第四轮决定。
- 支持多人独立账号，各自管理私人内容，账号间内容隔离；首版不做共享和协作。
- 统一使用“记录”表达内容，分为日记和笔记；日记关联记录日期，允许一天多篇，笔记按主题组织。
- 首版 AI 写作包含“零散要点整理成文”和“选中文本润色”；用户预览结果后决定是否采用。
- AI 从记录提取候选日程，用户确认时间与内容后加入日程表；缺失或不确定的信息要求补充。
- 首版日程管理包含日历查看、单次日程创建、修改、删除及基础冲突提示。
- 重复日程、提醒、外部日历同步暂不纳入首版必做范围，是否扩展后续决定。

## 第二轮已确认范围

- 以电脑端 Web 应用为主，手机支持基本浏览与编辑，不开发独立 App。
- 记录支持 Markdown 文本编辑与预览、标签、标题／正文关键词搜索和回收站；图片附件留待后续考虑。
- 接受第三方大模型 API 调用，仅发送用户主动提交的要点、选中文本或当前记录；首版不自动读取历史日记。此决定不代表授权助手发起付费调用。
- 日程支持明确起止时间和全天两种形式。
- 日记中的相对日期以记录日期为基准，笔记中的相对日期以操作当天为基准；确认界面显示具体日期。
- 时间冲突只提示，允许用户保存。
- 日程保留来源记录关联，但独立管理；修改原文不自动修改日程，删除原文不删除日程；再次提取时提示可能重复，由用户决定。
- README 中提及的待办、AI 时间复盘／回顾暂列扩展项，不属于首版必做范围。
- 首版优先完成“记录 → AI 辅助写作 → 提取候选日程 → 确认入表”的完整流程。

## 第三轮已确认范围

- 账号功能包含用户名／密码注册、登录、退出和修改密码；暂不做自助找回、第三方登录和管理后台。
- 先保证本机完整运行，将服务器部署作为最终交付目标，不要求长期公开运营；实际部署操作另行授权。
- 接受少量 AI API 费用，先设预算再开展付费验证；用户尚未给出金额，总预算上限待定，模型服务商待定。
- 开发时使用固定样例测试普通流程，验证 AI 效果时再调用真实模型。
- AI 超时、结果不完整或无法识别日程时，保留原文，明确提示失败或待补充信息，允许手动重试，不自动反复调用；普通记录与日程功能继续可用。
- 首版统一北京时间；全天事项作为日期标记，不与具体时段判定冲突。
- 回收站支持恢复和手动永久删除，不自动清理。
- 当前验收重点为功能完整、用户数据隔离、AI 提取效果可评估；学校要求明确后再对齐。
- 准备人工标注的中文记录，覆盖明确时间、相对日期、模糊安排、无日程和重复提取；统计提取结果并展示失败案例。
- 验证不同账号不能访问彼此内容，AI 不可用时基础功能仍可用。

## 第四轮已确认范围

- 接受 Vue → Spring Boot → 数据库，以及 Spring Boot → 独立 Python AI 服务 → 大模型 API 的架构。
- Spring Boot 负责账号、记录、日程、权限及业务数据保存；Python 使用 LangChain 负责文字整理、润色和候选日程提取，不直接读写业务数据库。
- 用户接受双后端带来的服务通信、调试和部署学习量。架构取舍见 [ADR 0001](adr/0001-python-ai-service.md)。
- 辅导节奏：共同明确目标与接口 → 助手解释思路并提供伪代码或小例子 → 用户编写代码 → 助手审查并协助定位问题 → 用户修改并验证。
- 助手默认不生成完整业务模块；用户明确要求时再提供局部示例。
- 用户每周可投入约 10 小时。
- 开发顺序为先完成基础账号、记录和日程，再接入 AI，最后进行评估、部署与论文材料整理。

## 需求边界汇总（已确认）

DayTrace 是面向个人使用、支持多账号隔离的日记／笔记与日程管理 Web 应用。首版完成记录管理、AI 辅助写作、从记录提取候选日程、用户确认入表和直接管理日程的完整流程；AI 结果须经用户确认后采用，AI 失败不影响基础功能。

首版不纳入共享协作、独立 App、图片附件、重复日程、提醒、外部日历同步、独立待办、AI 时间复盘、自动读取历史日记、自助密码找回、第三方登录和管理后台。扩展项重新讨论后才能纳入。

最终交付目标为可本机演示及服务器部署的系统、功能与账号隔离验证、AI 提取评估和失败案例，以及支持论文与答辩的过程材料；学校正式要求明确后再对齐。
