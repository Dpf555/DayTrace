# 日迹 DayTrace 页面原型

这是独立于正式 Vue 工程的可点击 HTML 原型，用于确认布局、页面职责和交互流程。没有安装前端依赖，也没有实现业务后端。

## 打开方式

- 直接双击本目录 `index.html`，无需联网。
- 或在仓库根目录执行 `node docs/prototype/serve.cjs`，浏览器访问 `http://127.0.0.1:4173`；按 Ctrl+C 停止服务。
- 所有编辑仅在当前页面内存中保留，刷新恢复初始样例；不会保存用户名或密码。

## 参考依据与设计取舍

参考用户指定的 `Talis智能学习辅助系统` 中的首页、学员管理、登录、修改密码 HTML，以及学员管理样式文件。这是 Axure 导出的原型，包含左侧分组导航、顶部账号操作、列表筛选、行操作和需求说明。

DayTrace 保留上述操作结构，但按本项目已确认的需求重新组织页面；不引入员工、班级、管理后台等 Tlias 业务。使用纸张白、鼠尾草绿、细分隔线与宋体标题，突出私人书写空间的安静感。所有图标均为本地内联线条图形，不依赖第三方资源。

## 页面清单

| 入口 | 页面与职责 | 主要交互 |
| --- | --- | --- |
| `#home` | 今日概览 | 最近记录、当日日程、新建记录、继续编辑 |
| `#records` | 我的笔记 | 左侧按时间分组的摘要列表、即时搜索、类型筛选；右侧阅读和编辑 |
| `#editor` | 笔记编辑兼容入口 | 与我的笔记使用同一工作区；标题、日期、标签、Markdown 编辑和阅读、保存 |
| 顶部 AI 写作按钮 | AI 写作 | 整理成文、选中段落润色、预览后采用 |
| AI 写作菜单中的提取按钮 | 候选日程确认 | 具体日期、可能重复、时间冲突、缺失信息补充、逐项确认 |
| `#calendar` | 日程日历 | 月份切换、点击日期新建、查看和编辑日程、删除 |
| `#trash` | 回收站 | 恢复记录、永久删除二次确认、不自动清理 |
| `#login`、`#register` | 登录与注册 | 必填项、演示密码长度、确认密码一致性 |
| `#settings` | 账号设置 | 修改密码表单、错误反馈、成功后回到登录 |

电脑端使用侧栏；窄屏使用横向导航，编辑页改为单栏，表格可横向滚动。弹窗使用原生 dialog，支持 Escape 关闭与键盘焦点约束。

## 推荐演示路径

1. 首页点击“继续上次的记录”，修改正文并保存，切换 Markdown 预览。
2. 点击“整理成文”，查看固定样例，选择取消或采用；润色前需选中正文文字。
3. 点击“提取候选日程”，查看具体日期、重复与冲突提示，确认第一项入表。
4. 对“周末去书店”点击“补充后确认”，填写缺失日期与时间后保存。
5. 打开日程日历，确认已添加的事项；新建全天事项，观察时间输入禁用及冲突提示消失。
6. 回到笔记列表，搜索、筛选、删除，再去回收站恢复。
7. 候选弹窗的“演示结果”可以切换未识别日程、AI 暂时不可用和手动重试。
8. 顶部退出后查看登录与注册；账号设置中的演示原密码为 `demo1234`，请勿输入真实密码。

## 规则与原型限制

- AI 采用固定文本与固定日程样例，**不分析用户输入，不调用模型**；样例明确以 2026-09-24 为日记日期。正式系统应按日记日期／笔记操作当天分别计算相对日期。
- 提取前将当前记录保存到演示内存，确保生成日程有来源记录。候选未经确认不会进入日历；已确认事项可在日历独立编辑。
- 手动日程校验标题、日期、开始和结束时间；仅演示同一天的定时事项与单日全天事项。
- 候选第一项的重复／冲突文案为固定样例；手动日程表单的重叠提示根据当前演示日程计算。再次提取可以再次添加，用户应核对重复提示。
- Markdown 仅演示标题、列表和加粗，所有输入先做 HTML 转义；正式系统需使用完整、安全的 Markdown 渲染方案。
- 标签使用单个文本标签示意；笔记以摘要列表展示全部匹配项；回收站保留单页表格，不实现真实分页。
- 日期固定为 2026-09-24，首页计数来源于当前样例集合；刷新页面会重置。
- 登录、注册、修改密码仅演示表单，不具备鉴权、账号隔离或真实密码更新能力。
- 原型不包含共享、提醒、重复日程、外部同步、图片附件等首版范围外功能。

- 按用户提供的 ima 笔记截图，使用窄导航栏、时间分组摘要列表、宽幅白色正文区和顶部工具栏。
- “我的记录”统一改为“我的笔记”。保留日记／笔记两种内容类型，不改变领域数据模型。
- 列表支持即时搜索、类型筛选、新建、切换与当前选中状态；未保存时切换笔记会确认。
- 顶部支持标题、加粗、列表 Markdown 插入，正文目录，阅读／编辑切换、保存、删除和 AI 写作菜单。
- 此处是 Markdown 编辑与阅读双模式，不是完整富文本编辑器；不包含截图中的知识库、发现或浏览模块。

## 今日概览：朝花夕拾

首页增加随机回顾卡片，展示往日笔记的日期、类型、标签、标题和正文摘要。“换一篇”从其他候选中随机选择，避免连续两次展示同一篇；“阅读全文”进入对应笔记的阅读界面。

回顾池包含日记和笔记两类内容，排除回收站内容及当天、未来日期。日期以原型统一演示日 2026-09-24 为准。只有一篇时禁用“换一篇”；没有候选时显示引导文案与新建入口。不使用 AI、不发送笔记内容。

所有工作区页面（今日概览、我的笔记、日程日历、回收站、账号设置）统一使用默认收缩的 82px 侧栏；窄屏统一改为顶部横向导航。
